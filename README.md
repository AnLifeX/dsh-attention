# dsh-attention

[![npm version](https://img.shields.io/npm/v/dsh-attention.svg)](https://www.npmjs.com/package/dsh-attention)
![Windows](https://img.shields.io/badge/Windows-10%2B-0078D6?logo=windows&logoColor=white)

DeepSeek Harness 提醒插件：会话需要 **审批 / 提问 / 选择**，或一轮对话结束时，显示可操作卡片、常驻鲸鱼娘宠物或系统通知。支持 Web、网页应用（PWA）和官方桌面版；桌面提醒功能需要 **Windows 10+**。

已核对 DSH `0.2.1-rc.5` 的会话、交互和设置接口，支持问答请求的 `wait.callId`，保留 `0.2.1-rc.2`、`0.2.0-rc.2` / `0.2.1-alpha.1` 及 `0.1.2-alpha.3` 的旧导航和卡片接口回退；不兼容更早使用 `apiProxy` 的版本。插件列表与设置页支持中文、英文。检查范围和已知限制见 [兼容性与桌宠调研](docs/compatibility-rc5-and-dsh-pet.md)。

2026-11-10 补查 DSH `0.2.2-rc.1` 发布包，现有核心接入点未发现不兼容变更；新版插件详情使用独立的中英文精简文档。该版 DSH CLI 要求 Node.js `24.9+`，插件自身的 Node.js 要求仍为 `18+`。本次为接口与自动测试核对，未完成新版宿主的端到端验收，详见 [0.2.2-rc.1 检查记录](docs/compatibility-022rc1.md)。

## 功能

- **网页休眠也能提醒。** 通知由 dsh 宿主发出，不走浏览器 `Notification`。标签被冻住时 JavaScript 停了，审批、提问、会话结束照样能弹窗。
- **卡片上直接处理。** 允许 / 拒绝、单选 / 多选、自定义输入（标题为「其他」）、写下一步，点完即提交，会话继续。不抢网页上的审批卡片。多题卡片会逐题勾选，点「提交」才一起发送。
- **官方卡自动关闭。** 原生卡先答完时，插件会把同一结果交给 DSH 官方审批 / 提问卡，让网页里的卡片自动关闭。已答记录没有时间过期限制，保留条数由 `settledMax` 控制。
- **跟着 dsh 主题。** 自制卡片亮色 / 暗色与当前页面一致，毛玻璃圆角；底部倒计时条从绿变到红。
- **三种卡片样式。** 默认自制卡片支持直接处理请求；宠物模式提供常驻鲸鱼娘和会话气泡；系统通知只负责点回会话。停用插件、切换样式或退出 DSH 后，常驻宠物退出。
- **回到已有会话。** 「回到会话」优先前置已经打开的 dsh 窗口或 Edge 应用，并切到对应会话；Web 版也可选择每次新开。
- **外观与预览。** 自制卡片的不透明度可调。切换宠物模式后显示 50%–200% 的大小滑块，开启设置页预览可实时查看缩放效果；保存后应用到桌面宠物。
- **多显示器跟随焦点。** 自制通知卡片默认出现在当前聚焦显示器的右下角；找不到焦点屏幕时自动回退到主显示器。宠物使用保存的位置。
- **按钮布局统一。** 自制通知卡片的审批按钮为「允许 / 拒绝」左右布局；会话结束 / 多选提交按钮在左侧，「回到会话」位于右上角关闭按钮左侧。宠物会话气泡使用悬停显示的操作图标。
- **当前窗口不打扰。** dsh 标签正在聚焦时不弹；切到别的窗口、标签，或页面隐藏时才提醒。
- **子代理结束提醒独立控制。** 「子代理会话结束」开关默认关闭。开启后弹窗会明确标注身份，并且不提供回复输入框。
- **设置页分组可调。** 在插件列表中启用或停用 **提醒**；打开 **设置 → 提醒**（铃铛），按「提醒范围 / 卡片外观 / 休眠唤醒」分组调整。改完点 **保存**，写入 `%USERPROFILE%\.dsh\dsh-attention-ui.json`，重启仍在。

## 宠物模式

在 **设置 → 提醒 → 卡片外观** 中选择 **宠物模式** 并保存：

- 鲸鱼娘常驻桌面；单击只唤回 DSH，保留当前页面。拖动可改变位置，松开后自动保存，重启后恢复所在屏幕和位置；屏幕断开或布局变化时调整到可见范围。
- 有会话时，底部显示折叠横条；鼠标靠近后变为数字气泡，点击展开会话消息，移开鼠标后仍保持展开，再次点击同一按钮收起。没有会话时隐藏横条和数字。
- 多条消息先以堆叠形式展示，点击堆叠展开列表。每项显示会话标题、最新消息或工具状态，已完成项带完成标记；列表根据宠物位置在上方或下方展开。
- 点击单条消息进入对应会话。悬停时显示快捷回复、终止和隐藏图标；终止仅用于运行中的会话，隐藏消息不会删除会话。
- 快捷回复为气泡内的单行输入框，**回车发送**，再次点击回复图标收起；子代理不提供直接回复。已完成消息在进入对应会话后移除，运行中的会话继续显示。
- 支持待机、工作、等待回答、完成、失败和拖动等动画；工作形态为吃大白饭。鼠标移动时短暂跟随视线，停下后恢复待机；关闭 Windows 动画效果时使用静态帧。
- 宠物大小在设置中调整。设置页预览用于检查形象和大小，完整动画在桌面宠物中播放。

## 安装

Web 版：

```bash
dsh plugin --profile web add dsh-attention
```

装完后重启 `dsh web`。

官方桌面版：优先在桌面应用的插件管理页安装 `dsh-attention`。同一个包自动适配桌面版和 Web，无需手动配置平台或端口。桌面版与 Web 的插件安装目录独立，安装到 `web` 不会自动启用到 `desktop`。

也可在桌面版菜单「管理 dsh 命令」安装桌面自带的命令，完全退出桌面应用，再执行：

```powershell
dsh plugin --profile desktop add dsh-attention
```

重新打开桌面版。桌面 profile 请使用桌面应用自带的 `dsh` 命令。

桌面版「回到会话」可唤回现有窗口，包括隐藏在托盘时，并切换到对应会话。桌面版始终复用窗口，不受 Web 的「新开」设置影响，也不执行浏览器休眠强制刷新；已答记录与通知设置仍生效。

## 更新

```bash
dsh plugin --profile web add dsh-attention@latest
```

更新完成后重启 `dsh web`。

桌面版在插件管理页更新并重启；也可完全退出后用桌面自带命令执行 `dsh plugin --profile desktop add dsh-attention@latest`。

## 用法

以下通知卡片操作以默认的自制卡片样式为例；宠物操作见上方「宠物模式」。

1. 模型申请提权：右下角出现允许 / 拒绝；点「回到会话」切回该会话。在右下角答完后，DSH 网页里的审批卡会自动关闭。
2. 提问 / 选择：主会话单选点选项即提交；多选或多题先勾选再点提交；也可在「其他」里自己写答案。DSH 不允许受控子代理直接向用户提问。
3. 主会话一轮对话结束：在窗口里写下一步并发送。子代理结束提醒默认关闭；开启后只提示并提供「回到会话」，不显示回复输入框。
4. Web 标签休眠后再回来：隐藏超过约 8 秒会自动刷新一次（等同 F5），把还挂着的审批卡片重放出来。正在输入时不会刷新；将隐藏刷新时间设为 `0`（关闭）或 `-1`（无限）都可关闭自动刷新。
5. 在插件列表中启用或停用 **提醒**，在 **设置 → 提醒** 里调整提示音、回到会话方式、样式、宠物大小、不透明度、停留时间、休眠刷新和已答记录条数。

## 配置

`cordis.patch.yml` 或 profile 里覆盖 `dsh-attention` 的 `config`：

| 字段 | 默认 | 含义 |
|---|---|---|
| `enabled` | `true` | 宿主配置开关；用户在插件列表中启用或停用插件 |
| `notifyApproval` | `true` | 提权审批 |
| `notifyQuestion` | `true` | 提问 / 选择 |
| `notifyIdle` | `true` | 一轮对话结束后的下一步输入 |
| `notifySubagentIdle` | `false` | 子代理会话结束通知；弹窗不提供回复输入框 |
| `notifyStyle` | `custom` | `custom` 自制卡片；`pet` 宠物模式；`system` 系统通知 |
| `notifyTimeoutSec` | `30` | 停留秒数；`-1` 无限（一直留到关掉），`0` 关闭自动消失。系统通知实际只有约 7 秒 / 25 秒两档 |
| `cardOpacity` | `0.78` | 自制毛玻璃卡片不透明度，`0.1`–`1`，越小越透 |
| `petScale` | `1` | 宠物大小倍率，`0.5`–`2`；设置页显示为 50%–200% |
| `openSessionMode` | `reuse` | Web：`reuse` 复用已有窗口；`new` 每次新开；官方桌面版始终复用 |
| `hiddenReloadMs` | `8000` | Web 标签隐藏多久后唤醒要刷新（毫秒；设置页按秒填写）；`0` 关闭自动刷新，`-1` 无限；官方桌面版不执行此刷新 |
| `settledMax` | `50` | 记住多少条「已用弹窗答过」的记录，用于回到窗口时自动关掉网页卡片；`0` 不记录，`-1` 不限 |
| `sound` | 系统默认提示音 | 设为 `false` 静音 |
| `choiceShellPath` | 自动 | 自制卡片使用的 PowerShell。默认优先 `pwsh` 7（启动更快），找不到时用 Windows PowerShell 5.1；可显式指定路径 |

插件会自动使用当前 DSH 实例的回环端口生成回调地址；多开时通知动作和会话切换会发给产生它的实例。回调路由只接受本机回环。

## 取值约定

时间和记录条数配置中，**`0` = 关闭该项功能，`-1` = 无限（不设上限）**，正数按各自单位取整。`cardOpacity` 和 `petScale` 为小数倍率，遵循各自的范围。

老版本用 `0` 表示「永久 / 不限制」；升级后第一次启动会自动把配置里的这些 `0` 改写成 `-1`，并写入 `schemaVersion` 标记 —— **只迁移一次**，之后你自己填的 `0` 不会再被改。

## 局限

- 选择 / 允许 / 下一步走右下角自制窗口，不依赖系统通知按钮回调。
- 自动刷新是对标签休眠后 pending 卡片丢失的缓解，不是给连接层打补丁。
- 自动关闭依赖宿主中的「已答记录」和客户端缓存：超过 `settledMax` 条后最旧的会被丢弃，宿主重启或清除浏览器缓存也可能使记录不可用，此时若卡片被重放，需要手动处理。
- 自制卡片优先用 `pwsh` 7，缺失时回退 Windows PowerShell 5.1；系统通知仍用 5.1 的 WinRT Toast。首次加载插件时会在当前用户注册 `dsh-attention:` 协议。
- 自制卡片、桌面宠物和系统通知只在 Windows 上展示；其它系统装上后设置页和 Web 休眠唤醒刷新仍可用。
- 插件列表与设置页支持中文、英文；原生通知卡片和宠物会话操作提示目前使用中文，会话标题与消息保留原文。
- Web 的「回到会话」按窗口标题 / PWA 名称匹配；dsh 若在后台标签里，可能只能把整个浏览器前置。普通浏览器标签建议选「新开」。官方桌面版使用 `dsh://open`，不依赖浏览器窗口匹配。
- 多开 DSH 时端口能区分实例和目标会话，但 Windows 无法可靠地前置普通浏览器里的指定标签；需要精确打开时选「新开」，独立 Edge 应用窗口的复用更可靠。
