# 提醒

审批、提问或一轮对话结束时，在桌面提醒你，并直接处理下一步。

- **直接操作**：允许或拒绝审批、回答单选 / 多选问题、发送下一步消息。
- **三种样式**：可操作卡片、常驻鲸鱼娘宠物、系统通知。系统通知点击后回到会话处理。
- **宠物会话气泡**：查看会话状态，进入会话、快捷回复、停止运行或隐藏消息。
- **减少打扰**：DSH 窗口聚焦时不弹通知；子代理完成提醒默认关闭。
- **网页休眠后继续**：宿主负责提醒，原生卡答完后同步关闭网页卡片。

## 开始使用

启用插件后，打开 **设置 → 提醒**，选择提醒范围与卡片样式，点击 **保存**。宠物大小、不透明度、提示音和通知停留时间都可调整。

支持 DSH Web、PWA 和官方桌面版；**桌面卡片、宠物与系统通知需要 Windows 10+**。Web 与桌面版需分别安装插件。

限时问题结束前台等待后，请在 DSH 官方页面继续回答。
