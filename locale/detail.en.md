# Attention

Get a desktop reminder when a session needs approval, asks a question, or finishes a turn, and act on it directly.

- **Take action**: allow or reject approvals, answer single or multiple choice questions, and send your next message.
- **Three styles**: interactive cards, a resident whale girl desktop pet, or system notifications. System notifications take you back to the session to respond.
- **Pet session bubbles**: check status, open a session, send a quick reply, stop a running session, or hide a message.
- **Fewer interruptions**: notifications stay quiet while DSH is focused. Subagent completion reminders are off by default.
- **Browser sleep support**: the host sends reminders, and answers from native cards also dismiss the matching web cards.

## Get started

Enable the plugin, open **Settings → Attention**, choose your notification scope and style, and select **Save**. You can also adjust pet size, card opacity, sound, and notification duration.

Supports DSH Web, PWA, and the official desktop app. **Desktop cards, the pet, and system notifications require Windows 10+.** Install the plugin separately for Web and desktop.

When a timed question ends its foreground wait, continue answering on the official DSH page.
